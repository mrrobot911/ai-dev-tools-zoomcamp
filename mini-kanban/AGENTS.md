# Project Instructions

## Project
Mini Kanban Board.

## Architecture
- Follow `spec.md`.
- Keep frontend and backend separated.
- Use `openapi.yaml` as the source of truth for frontend/backend communication.
- Keep frontend API calls behind the service layer.
- Keep the backend database-agnostic.

## Development
- Inspect the existing code before making changes.
- Prefer small, focused changes.
- Do not add features that are not in `spec.md`.
- Keep existing functionality working.

## Testing
- Add or update tests when changing behavior.
- Run relevant tests before committing.

## Dependencies
- Frontend: use the existing package manager and project setup.
- Backend: use `uv`.

## Git
- Make small, focused commits.
- Use descriptive commit messages.
